# HypeScript 公式サイト

小説・創作同人サークル「HypeScript（ハイプスクリプト）」の公式ウェブサイトです。

このサイトでは、サークルの活動内容やメンバー、制作物、参加イベント、加入案内、SNS情報をご覧いただけます。作品世界を題材にした無料のブラウザゲームも公開しています。
